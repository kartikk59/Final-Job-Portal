# CareerHub

CareerHub is a career and job portal that helps candidates find jobs and internships, manage applications, explore learning resources, and connect with mentors. Recruiters can post opportunities, while administrators have a separate dashboard.

## Features

- Browse job and internship listings
- Save jobs and track applications
- Create a candidate profile
- Explore learning resources and interview experiences
- Find mentors and book mentorship sessions
- Sign up and log in as a candidate or recruiter
- Recruiter and admin dashboards
- Role-based access to protected pages

## Tech Stack

### Frontend
- React 19
- Vite
- React Router
- JavaScript and CSS
- TypeScript for some mentorship files
- Lucide React icons

### Backend
- Node.js
- Express 5
- MongoDB with Mongoose
- JWT authentication using HTTP-only cookies
- bcryptjs for password hashing
- Multer for file uploads
